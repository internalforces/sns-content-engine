실행 작업

운영 워크플로 실행

후보 수집

새 소스 후보 찾기

현재 스케줄러 discover 경로를 그대로 실행합니다. 이 작업은 후보를 찾기만 하고 데이터베이스에는 저장하지 않습니다.

수집 저장

새 항목 저장까지 진행

발견한 후보를 중복 검사 후 저장해 아티클 상태 화면과 이후 보강 단계에서 바로 사용할 수 있게 만듭니다.

기사 보강

저장된 기사 본문 보강

이미 저장된 소스 항목에 대해 HTML 수집, 본문 추출, 요약 재생성을 실행합니다. 정책상 막힌 항목은 그대로 건너뜁니다.

백필

미래 발행 슬롯 채우기

기존 플래너와 승인된 초안을 사용해 각 경로의 백로그 목표치까지 부족한 예약 발행 작업을 만듭니다.

전체 파이프라인

발견부터 초안 생성까지 한 번에

현재 로컬 파이프라인 경로를 그대로 실행해 수집 저장, 기사 보강, 브리프 생성, 초안 생성을 한 번에 진행합니다. 생성된 초안은 기존 정책대로 검토 대기로 남습니다.
