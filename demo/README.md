# 공개 가능한 로컬 데모

실제 계정, API 키, 운영 데이터 없이 콘텐츠 운영 콘솔의 주요 흐름을 확인하는 데모입니다.

```bash
./demo/run_demo.sh
```

브라우저에서 `http://127.0.0.1:8000/console/`을 열어 실행 이력, 기사 상태, 검수 대기열, 발행 작업, 스케줄러를 확인합니다. 데이터는 `demo/demo.db`에 생성되며 Git에 포함되지 않습니다. 종료 후 다시 실행하면 동일한 공개 샘플 데이터로 초기화됩니다.

동작 영상: [sns-content-engine-demo.mp4](sns-content-engine-demo.mp4)

영상과 샘플에는 공개 예시 도메인만 사용하며 로그인 정보나 외부 발행 권한은 포함하지 않습니다.
